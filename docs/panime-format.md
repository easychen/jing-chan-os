# `.panime.png` 裸眼 3D / 动态壁纸规范

小鲸同学（JingChan）原生支持单文件 `.panime.png` 动态壁纸格式：它本质上是一张完全合法的标准 PNG 图片（任何看图软件均可直接预览封面），同时在 PNG 私有块 `paNe` 中嵌入了帧图集或视差动画元数据。

## 设计特点
- **单文件便携**：一张 `.panime.png` 即可通过微信、Git 仓库或「壁纸」App 直接上传与分享，无需压缩包解包。
- **零破坏兼容**：普通图片查看器会读取标准 `IDAT` 主图作为静态封面；小鲸同学客户端解析 `paNe` 块后自动渲染丝滑循环动画与重力/视差效果。
- **自适应状态栏**：客户端在切换壁纸时自动对顶部 12% 区域做亮度采样，浅色天空背景自动切换黑色状态栏文字，深色夜景背景自动切换白色文字。

## 在小鲸同学中使用
1. 打开桌面「壁纸」App；
2. 上传任意静态图片（`.png` / `.jpg` / `.webp`）或 `.panime.png` 动态壁纸；
3. 宿主服务端（`POST /jphone/api/wallpaper/upload`）会原样保留 `paNe` 二进制块并同步至所有在线设备（桌面端与手机端）。
